## Featured project

### [IPTV](https://github.com/4kings6114/IPTV)

[![Tests](https://github.com/4kings6114/IPTV/actions/workflows/tests.yml/badge.svg?branch=main)](https://github.com/4kings6114/IPTV/actions/workflows/tests.yml)

A Python-based toolkit for building and maintaining M3U playlists, with automated checks and a static web dashboard.

- **Automated playlist builds** with source refreshes, stream health checks, alternative selection, backups, and publication guards.
- **A searchable dashboard** with channel filters, local favorites, and personal playlist/profile downloads.
- **Bandwidth-aware profiles** using verified HLS alternatives and advertised bitrate where available; no video transcoding.
- **XMLTV guide validation** with explicitly reviewed channel mappings. Matched guide coverage is still limited.
- **Reliability history and targeted alerts**, designed to distinguish fresh checks from cached results.
- **GitHub Actions automation** for testing, publication, and GitHub Pages deployment.

**Explore:** [Dashboard](https://4kings6114.github.io/IPTV/) · [Source & documentation](https://github.com/4kings6114/IPTV) · [Main playlist](https://4kings6114.github.io/IPTV/playlist.m3u) · [Low-bandwidth playlist](https://4kings6114.github.io/IPTV/profile-low-bandwidth.m3u)

## Technologies used in IPTV

Python · JavaScript · HTML/CSS · GitHub Actions · M3U · XMLTV

## Current focus

- Expanding verified programme-guide coverage without guessing channel identities.
- Making decoder tools available for production playback samples.
- Collecting multi-day reliability evidence and improving stream selection.

> This project manages playlists; it does not host video. A successful structural check does not guarantee playback on every network or in every region. Stream availability and content rights remain subject to the providers.
