# اعمال معرفی عمومی حساب 4kings6114

## وضعیت واقعی

این بسته متن‌های آمادهٔ معرفی را فراهم می‌کند؛ وجود فایل‌ها در مخزن IPTV به‌تنهایی پروفایل حساب را تغییر نمی‌دهد.

در ۲۰۲۶-۱۱-۱۰، درخواست‌های اولیهٔ نوشتن Bio، About مخزن و Topics با پاسخ `403 Resource not accessible by integration` رد شدند. در تلاش مجدد، About و Topics همچنان ۴۰۳ گرفتند، نوشتن Bio با خطای موقت ۵۰۲ روبه‌رو شد و بررسی بعدی نشان داد Bio هنوز خالی است. ساخت مخزن هم‌نام پروفایل نیز با خطای دسترسی `createRepository` رد شد؛ هیچ مخزن جدیدی ایجاد نشد.

دسترسی خواندن اطلاعات عمومی و کار با کد مخزن به معنی مجوز ویرایش تنظیمات حساب/مخزن نیست. از طرف این کار، هیچ نام کاربری، نام شخصی، وب‌سایت حساب یا تنظیم امنیتی تغییر نکرده است. عنوان README از نام نمایشی عمومیِ مشاهده‌شدهٔ `Mehdi_lo0lo0` استفاده می‌کند؛ خود نام نمایشی را ویرایش نمی‌کند.

برای اعمال خودکار این بخش‌ها، مالک باید دسترسی‌های اتصال گیت‌هاب را در تنظیمات مربوطه بررسی کند. گذرواژه، توکن یا کد ورود را در چت یا مخزن قرار ندهید. روش دستی زیر نیز کافی است و به ارائهٔ هیچ اعتبارنامه‌ای نیاز ندارد.

## ۱. Bio حساب

به [پروفایل](https://github.com/4kings6114) بروید، **Edit profile** را انتخاب کنید و فقط Bio را با متن زیر پر کنید؛ سپس **Save** را بزنید:

```text
Building tools for IPTV playlist automation and lightweight dashboards.
```

نام نمایشی، محل زندگی، شرکت و اطلاعات تماس اختیاری‌اند؛ هیچ اطلاعات شخصی حدس زده نشده است. نام کاربری را تغییر ندهید.

## ۲. بخش About مخزن

در [صفحهٔ مخزن IPTV](https://github.com/4kings6114/IPTV)، روی چرخ‌دندهٔ کنار **About** کلیک کنید.

```text
Automated IPTV playlist builder with health checks, bandwidth-aware profiles, and a static dashboard.
```

**Website:**

```text
https://4kings6114.github.io/IPTV/
```

**Topics:** هر مورد را جداگانه اضافه کنید و برچسب‌های موجود را نگه دارید:


سپس **Save changes** را بزنید. لازم نیست visibility، شاخهٔ پیش‌فرض، Pages یا تنظیمات امنیتی مخزن تغییر کند.

## ۳. README پروفایل

برای نمایش معرفی در بالای پروفایل، یک مخزن عمومی با نام دقیق **`4kings6114`** زیر حساب **`4kings6114`** لازم است. هنگام بررسی، چنین مخزن عمومی‌ای دیده نشد.

1. در گیت‌هاب **New repository** را انتخاب کنید.
2. Owner را `4kings6114` و Repository name را دقیقاً `4kings6114` بگذارید.
3. گزینهٔ **Public** و ساخت README را انتخاب کنید؛ این معرفی عمومی خواهد بود، پس اطلاعات خصوصی در آن نگذارید.
4. پس از ساخت، محتوای README پیش‌فرض را با محتوای فایل [`README.md`](README.md) در همین پوشه جایگزین و ذخیره کنید.
5. صفحهٔ پروفایل را باز کنید و نمایش معرفی، badge تست‌ها و لینک داشبورد را بررسی کنید.

فایل آماده عمداً شامل آمار ثابت و زودمنقضی، ادعای تخصص یا سابقهٔ تأییدنشده، badge مجوز انتخاب‌نشده، تضمین پخش یا تصویر ساختگی داشبورد نیست. می‌توان بعداً یک تصویر واقعی و بدون اطلاعات حساس از داشبورد اضافه کرد.

## ۴. پین‌کردن پروژه

در صفحهٔ پروفایل **Customize your pins** را انتخاب کنید، مخزن **IPTV** را علامت بزنید و **Save pins** را انتخاب کنید. در API عمومی بررسی‌شده، عملیات پین‌کردن مخزن پروفایل ارائه نشده است؛ از عملیات پین‌کردن issue به‌جای آن استفاده نکنید.

- کارت IPTV در بخش پروژه‌های پین‌شده دیده می‌شود.
- About مخزن توضیح، لینک داشبورد و پنج برچسب را دارد.
- README بالای پروفایل نمایش داده می‌شود؛ صرفاً قرارگرفتن آن در مخزن IPTV کافی نیست.
- نام کاربری، اطلاعات شخصی، فایل‌های تولیدی IPTV و تنظیمات انتشار دست‌نخورده‌اند.
